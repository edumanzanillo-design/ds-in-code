# ds-in-code — Portfolio personal de Edu Manzanillo

## Stack
- React con Vite (JavaScript, no TypeScript)
- Chakra UI v3
- React Router para navegación

## Colores de marca
- Azul principal: #0371B7
- Texto principal: #222222
- Botón teal (UI Components): colorPalette="teal"

## Convenciones visuales
- Fondo de puntos en todas las páginas: radial-gradient(circle, #00000025 1px, transparent 1px) con bgSize="24px 24px"
- bg="white" siempre explícito en el Box principal de cada página

## Notas
- El proyecto usa JavaScript (.jsx), no TypeScript (.tsx)
- Los snippets de Chakra están en src/components/ui/
